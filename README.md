# YU-GI-OH DESIGN LAB

유희왕 커스텀 테마의 **원문·CDB·Lua를 검수하는 무료 브라우저 연구소**입니다.

## V0.3.1 — 카드 원문 집중 읽기

- 자료실에서 카드를 선택하고 **「⤢ 이 카드 원문 크게 보기」**를 누르면 화면 전체를 읽기 공간으로 사용할 수 있습니다.
- 처음에는 **18px 글씨**로 원문 효과를 모두 펼쳐서 표시합니다. **가− / 가＋**로 글씨 크기를 조정할 수 있습니다.
- 왼쪽에서 카드 검색·선택, 상단에서 이전·다음 카드 이동, **ESC**로 닫기를 지원합니다.
- 원문 카드가 로딩된 뒤에는 필요 없는 업로드 안내·통계 영역을 숨겨 기본 카드 패널도 더 넓게 사용합니다.
- 집중 읽기는 카드 효과를 보기 좋게 재배치할 뿐 원본 TXT를 수정하지 않으며, 분석·검증 결과로 간주하지 않습니다.

## V0.3 — 작업실형 화면 개선

- 상단 또는 왼쪽 메뉴에서 **카드 자료실 / 교차 검수 / 덱 연구소(준비 중)**를 전환합니다.
- PC에서는 긴 페이지를 스크롤하는 대신 **카드 목록과 효과 상세 패널만 각각 스크롤**합니다.
- 카드 효과는 ①·②·③을 따로 접거나 펼치며, \`모두 펼치기\` 기능을 제공합니다.
- 원문 메모는 자료실 하단의 접이식 서랍에서 확인합니다.
- 레이아웃만 바뀌었으며 기존 ZIP·TXT 불러오기, 카드 검색, CDB·Lua 정적 검사 기능은 유지됩니다.
- 탭 선택은 주소의 \`#library\`, \`#audit\`, \`#deck\`에 반영됩니다. 새로고침하면 탭은 유지되지만 **브라우저 메모리의 업로드 파일은 다시 불러와야 합니다.**
- 덱 연구소는 현재 안내 화면이며 실제 분석 기능은 미구현입니다.

## V0.1 — 원문 자료실
- 5대 세력 TXT 또는 ZIP 업로드, 카드별 분류·검색·열람
- 카드 원문에 기재된 메모를 보존하고 기본 효과 키워드 추출
- 기초 진단 Markdown 보고서 내려받기

## V0.2 — 원문·CDB·Lua 교차 검수
- **한 번에 여러 파일 선택**: 원문 TXT/ZIP + 각 테마의 시험패키지 ZIP 또는 개별 CDB/Lua
- CDB: SQLite의 \`datas\`/\`texts\` 테이블에서 ID·이름·설명·선택지 문자열 읽기
- Lua: 카드 ID의 \`c<ID>.lua\` 대응, \`initial_effect\` 존재, 공용 \`*_common.lua\` 참조 검사
- 효과 문구: 원문과 CDB의 번호 붙은 효과 항목을 대조하고 차이와 순서 확인
- 파일 버전 충돌, 카드 ID/이름 누락, 선택지 설명 문자열 누락 가능성 경고
- 실제 EDOPro 구동 없이 **정적 진단 보고서** Markdown 파일로 저장
- CDB만 업로드한 경우에도 **CDB↔Lua 검사는 가능**, 설계 원문 대조는 미검증으로 표시

### 실제 사용
1. 첫 화면의 **V0.2 교차 검수**까지 내려갑니다.
2. **검수 자료 불러오기**에서 \`백업 종언성서-녹트루나.zip\`과 \`파계잔영_V0.9.1_...zip\`처럼 원문·실행 패키지 파일을 **동시에 선택**합니다.
3. 오류 후보/검토 필요 탭을 선택해 카드별 근거를 확인합니다.
4. \`종언성서_원문_CDB_Lua_정적검수_V0.2.md\` 보고서를 내려받습니다.

> **검사 수준 경계**: 문구 비교는 유사한 뜻의 다른 표현도 차이로 표시할 수 있습니다. Lua 검사는 파일과 일부 정적 패턴만 확인하므로, Lua 구문 전체·EDOPro API·효과의 적법한 처리·실전 성능까지 판정하지 않습니다. '오류 후보'가 반드시 실제 버그를 뜻하지는 않습니다.

## 파일과 개인정보
- 업로드한 파일을 서버로 보내지 않습니다. 브라우저 메모리에서만 분석하고 탭을 닫으면 사라집니다.
- 첫 실행 시 JSZip과 sql.js 코드·WASM은 공개 CDN을 통해 로드됩니다. **실제 카드 ZIP·CDB·Lua 데이터는 CDN으로 업로드하지 않습니다.**
- GitHub 저장소에는 업로드한 원본 CDB·Lua·개인 파일을 자동 커밋하지 않습니다.
- 공개 페이지를 사용하더라도 업로드 내용이 공개 저장소에 게시되지는 않습니다.
