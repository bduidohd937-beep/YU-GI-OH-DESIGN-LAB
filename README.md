# YU-GI-OH DESIGN LAB

유희왕 커스텀 카드군의 **원문 관리·검색·기초 규칙 점검**을 위한 무료 웹 도구입니다.

## V0.1 목표
- 종언성서 5대 세력의 **원문 TXT 5개 또는 해당 TXT가 들어 있는 ZIP**을 읽고 카드별로 정리
- 테마별 분류, 카드 효과 전문 보기, 키워드 검색
- 자동 키워드 분류·미결 사항 표시·검수 보고서 내려받기
- 파일 내용은 **사용자의 브라우저 안에서만** 처리하며 서버로 전송하지 않음

> 이 단계의 진단은 규칙 기반 **검토 보조**입니다. OCG 재정 적법성, Lua 엔진 구동, 덱 강도를 자동으로 보증하지 않습니다.

## 실행
정적 웹 프로젝트입니다. 웹 호스팅을 이용하거나 로컬에서 다음과 같이 실행할 수 있습니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000` 을 여세요.

## 테스트
Node.js 18 이상에서:

```bash
node --test
```

## 파일 보호
- 공개 저장소에는 사용자가 업로드한 원문 ZIP, CDB, Lua, 덱 원본을 넣지 않습니다.
- 원문은 기본적으로 서버에 저장하지 않고, 탭을 닫으면 메모리에서 사라집니다.
- ZIP 해제에는 오픈소스 [JSZip](https://stuk.github.io/jszip/) (MIT 또는 GPLv3)을 사용합니다. 라이브러리 자체만 CDN에서 불러옵니다.
- 파일 업로드 및 자동 AI API 호출 기능은 없습니다.

## 예정 작업
1. V0.1 원문 분석 및 검색
2. 원문 ↔ CDB ↔ Lua 불일치 검사
3. 로컬 EDOPro 재현 테스트
4. AI ARENA / 자동 전개 분석 연결

## 설계 원칙
**원문 사실 / 정적 규칙 검사 / 실전 검증 / AI 추정**을 구분합니다.

파일명은 사람이 관리하는 자료에 대해 한글을 우선하고, 엔진·코드 경로는 호환성을 우선합니다.
